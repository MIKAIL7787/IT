Три действия (Пример YouTube)
A. Загрузка видео
На сервер уходит: видеофайл (чанками), название, описание, теги, превью, ID канала, токен авторизации.
Сервер проверяет: валидность токена, права на канал, формат/размер файла, лимиты, наличие копий.
Куда сохраняется: файл → в объектное хранилище (Blob/GCS), метаданные → в БД, задача на транскодинг → в очередь.
Возвращается: videoId, статус "processing", URL превью, прогресс загрузки.

B. Лайк под видео
Уходит: videoId, userId, тип реакции, токен.
Проверяет: авторизация, существование видео, не превышен ли лимит лайков, есть ли уже реакция (toggle).
Сохраняется: в БД счётчиков + лог событий.
Возвращается: новое число лайков, подтверждение, иногда анимация.

C. Просмотр видео
Уходит: videoId, позиция плеера, качество, устройство, cookies/токен, факт старта/конца.
Проверяет: доступность видео, права, монетизация, не бот ли.
Сохраняется: событие просмотра → в аналитику, история просмотров → в профиль, прогресс → для "Продолжить просмотр".
Возвращается: манифест потока, реклама, рекомендованные видео, следующий чанк.
